# ATrace 1.1.1

- 版本号提升到 1.1.1 (versionCode 1101)

## 新增

- 选项页新增「按 PID 注入」独立入口：可直接对任意 pid 注入，无需先选择进程
  （native ELF 等没有包名的进程只能按 PID 注入）
- 按包名注入时若目标未运行，可自动拉起应用、等进程起来后再注入
- 「注入后自动连接 socket」开关；SO 通道状态实时显示（绿=已连接 / 红=未连接）
- 搜索 / 保存 选项卡右上角数量角标（结果数 / 已保存条数）
- 保存地址前新增「选择类型」，列出各内存格式及其数值范围
- 跳转链接库支持按库名搜索；点击结果后自动关闭弹窗
- 点击对话框外部空白区域即可关闭（返回上一级）

## 修复

- 改善（结果过滤）闪退：原实现一次性构造全部命中页表（20 万条约 800MB）
  会抛 bad_alloc 导致 SIGABRT；改为分块处理并串行化远程读取，内存有界
- 改善比较统一按 64 位进行，BYTE/WORD/DWORD 遇到负数目标值会全部漏判
- D 类型负数溢出显示为正整数（raw 未做按类型符号扩展）；QWORD 现按有符号处理
- 搜索页「保存选中」只遍历当前页，跨页勾选的结果会被静默丢弃
- 输入法（手机键盘）菜单里的复制无效：后台窗口写剪贴板被系统静默丢弃；
  新增 ClipboardEditText 接管并自动升级到兼容通道
- Lua 脚本页补充复制按钮（支持复制选中片段 / 全文），输出区支持长按复制
- 链接库搜索、注入对话框等在键盘弹出后顶部内容被挤出屏幕（对话框改为居中滚动）

## 说明

- 本 APK 为 arm64-v8a debug 变体；使用注入/断点/内存搜索需要 root
- 任务 1 的改善功能、任务 3 的拉起注入、水波纹等仍需真机复测
